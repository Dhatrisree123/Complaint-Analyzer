# Complaint Analyzer

Complaint Analyzer is a Generative AI project built using Python, Google Colab, and the Gemini API. It takes customer complaints as input and analyzes them based on the information provided.

The system identifies the complaint category, severity, root issue, and recommended action, and returns the result in a structured JSON format. It also uses severity rules to distinguish between high, medium, and low-impact complaints while avoiding unsupported assumptions.

The project was tested with different types of complaints, including financial loss, major service issues, minor inconveniences, and unclear complaints.
